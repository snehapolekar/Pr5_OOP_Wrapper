# 🐍 Python OOP – Employee Management System 👨‍💼

## 📌 Project Overview

This project is a simple **Employee Management System** created using **Python Object-Oriented Programming (OOP)** concepts. 🐍

The project demonstrates how different types of people can be managed through classes and objects. It includes **Person 👤, Employee 👨‍💼, and Manager 🧑‍💼** with their respective details and operations.

## 🎯 Objectives

- 📚 Understand basic Object-Oriented Programming concepts.
- 🏗️ Create and use classes and objects.
- 🔗 Demonstrate inheritance between classes.
- 🔐 Use encapsulation for employee information.
- 📋 Store created objects using lists.
- 🖥️ Display details according to the user's choice.
- 📦 Handle empty lists when no details are available.

## 🧩 Main Classes

### 👤 Person

The **Person** class stores basic information:

- 🧑 Name
- 🎂 Age

It also provides functionality to display person details.

### 👨‍💼 Employee

The **Employee** class inherits from the **Person** class.

It contains:

- 🧑 Name
- 🎂 Age
- 🆔 Employee ID
- 💰 Salary

Getter and setter methods are used for Employee ID and salary.

### 🧑‍💼 Manager

The **Manager** class inherits from the **Employee** class.

It contains:

- 🧑 Name
- 🎂 Age
- 🆔 Employee ID
- 💰 Salary
- 🏢 Department

## 🔐 OOP Concepts Used

### 1️⃣ Encapsulation 🔒

Employee ID and salary are handled using private attributes and getter/setter methods.

### 2️⃣ Inheritance 🌳

The project uses the following inheritance structure:

**Person 👤 → Employee 👨‍💼 → Manager 🧑‍💼**

This allows properties and methods to be reused from parent classes.

### 3️⃣ Classes and Objects 🏗️

Classes are used as blueprints, while objects are created for Person, Employee, and Manager.

### 4️⃣ Lists 📋

Separate lists are used to store created Person, Employee, and Manager objects.

## 🖥️ Available Operations

The system provides the following menu:

1️⃣ Create a Person 👤  
2️⃣ Create an Employee 👨‍💼  
3️⃣ Create a Manager 🧑‍💼  
4️⃣ Show Details 📄  
5️⃣ Exit 🚪

The **Show Details 📄** option allows the user to select Person, Employee, or Manager details.

## 📦 Empty List Handling

The project checks whether a list contains any objects before displaying details. ✅

If no object has been created, the system displays an appropriate message such as:

**⚠️ No Person details available.**

Similar messages are shown for Employee and Manager when their lists are empty.
